# 🍽️ Swiggy Restaurant Data Analysis using SQL

## 📌 Project Overview

This project demonstrates end-to-end SQL data analysis using a real-world Swiggy restaurant dataset. The objective was to analyze restaurant performance, customer ratings, pricing, delivery time, and city-wise trends by solving practical business problems using MySQL.

The project focuses on writing optimized SQL queries and applying analytical thinking to answer real business questions.

---

## 📊 Dataset Information

- **Dataset:** Swiggy Restaurant Dataset
- **Total Records:** 8,680+
- **Database:** MySQL
- **Tool Used:** MySQL Workbench

### Dataset Columns

- Restaurant
- City
- Food Type
- Price
- Average Ratings
- Total Ratings
- Delivery Time
